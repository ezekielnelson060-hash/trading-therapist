# TiltShield — product framing

**Promise:** It stops you from repeating the trading behavior that is costing you money.

Not a trade journal. Not a generic AI chatbot. **Behavioral risk control.**

## Loop

Observe (broker data) → Detect (tilt engine) → Explain (signals + coach) → Intervene (pause / override log) → Learn (baseline + check-ins).

## Core surfaces

| Surface | Job |
|---------|-----|
| State | Tilt score, signals, do-not-trade |
| Constitution | Rules the engine enforces against |
| Data | MT5 webhook, IBKR Flex, demo seed |
| Check-in | Motive → outcome correlation |
| Weekly | Behavior headline, cost of behavior |
| Coach | Evidence-based, grounded in tilt + trades |

## Positioning lines

- Know when your trading is breaking down before your account does.
- Your trading plan is useless if you don't follow it. We monitor the gap.
- P&L is not the headline — behavior is.

## Pricing sketch (not enforced in code yet)

- Free: limited history, basic tilt
- Trader: brokers + baseline + autopsy + coach
- Pro: alerts, cost-of-behavior, multi-account
- Teams: prop / coach aggregated risk
